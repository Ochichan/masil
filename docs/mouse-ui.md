# 마우스 UI와 설정 화면

`rmux`를 `-f` 없이 시작하면 tmux 기본값 위에 rmux UI 레이어가 적용된다. 처음 실행부터 창·pane·세션을 마우스로 만들고 조작할 수 있다. tmux 옵션과 키 테이블의 기본값 자체는 바꾸지 않는다.

## 마우스로 할 수 있는 일

| 위치 | 동작 |
| --- | --- |
| 상태줄 `rmux` | rmux 메뉴: 설정, 에이전트, 새 창, 새 세션, 세션과 창 목록, 세션 저장, 세션 불러오기, 오른쪽·아래로 분할, 레이아웃, 키 목록, tmux 설정 다시 읽기, 분리 |
| 창 목록 뒤 `+` | 새로 만들기 메뉴: 새 창, 새 floating pane, 현재 pane을 오른쪽·아래로 분할 |
| 창 탭 클릭·휠 | 창 선택·이전/다음 창 (tmux 기본) |
| 현재 창 탭 오른쪽 클릭 | 창 메뉴: 이름 변경, 새 창, 종료 등 (tmux 기본) |
| `Settings` | 설정 화면 |
| pane 제목 클릭 | pane 이름 변경 |
| pane 제목 드래그 | floating pane·묶음 이동. 타일 pane은 위쪽 경계를 옮긴다 |
| pane 제목의 `+` | 그 pane의 분할 메뉴: 오른쪽·아래로 분할, 새 floating pane |
| pane 제목의 `float`·`zoom`·`x` | floating 전환, 확대, 닫기 (tmux 기본 버튼) |
| pane 오른쪽 클릭 | pane 메뉴: 분할, 확대, 교환, 종료 등 (tmux 기본) |
| pane 경계 드래그 | 크기 조절 (tmux 기본) |
| floating pane 윗테두리·모서리 드래그 | 이동·크기 조절. floating 묶음은 한 덩어리로 움직인다 |
| 스크롤바 | 스크롤할 때 나타나며 끌어서 이동한다 |
| 사이드바 `<`·`>` | 사이드바 폭 접기·펴기 |

메뉴는 클릭한 뒤 버튼을 떼도 열려 있다. 포인터를 항목 위로 옮겨 클릭하면 실행하고 바깥을 누르면 닫힌다. 레이어는 `@rmux-menu-stay-open`으로 이 동작을 켜며 tmux 기본 메뉴 바인딩은 그대로 쓴다.

## floating 묶음

floating pane을 `+` 메뉴나 pane 제목의 `+`로 나누면 floating 묶음이 된다. 묶음 안의 pane들은 떠 있는 사각형 하나를 타일처럼 나눠 쓴다. 바깥 윗테두리를 끌면 묶음 전체가 움직이고, 바깥 모서리와 테두리를 끌면 묶음 크기가 바뀌며 안의 pane이 비율대로 따라간다. 안쪽 경계선을 끌면 이웃 pane끼리 크기를 나눈다. pane 하나를 누르면 묶음 전체가 앞으로 나온다. 묶음 pane을 닫으면 이웃 pane이 자리를 채우고, 하나만 남으면 보통 floating pane이 된다. 묶음 pane의 `tile`은 그 pane만 묶음에서 빼 타일 레이아웃에 넣는다.

명령으로는 `split-window -G`가 floating pane을 묶음으로 나누고, 이미 묶음에 든 pane은 `-G` 없이도 묶음 안에서 나뉜다. `join-pane -t <묶음 pane>`은 다른 pane을 묶음에 넣는다. `resize-pane`은 그 방향으로 나뉜 묶음 안에서 경계를 옮기고, 그 방향으로 나뉘지 않았으면 묶음 전체 크기를 바꾼다. `-G` 없이 혼자 떠 있는 pane을 나누면 tmux처럼 옆에 따로 뜬 pane이 생긴다.

rmux 메뉴의 레이아웃은 좌우로 나란히, 위아래로 쌓기, 왼쪽에 큰 pane, 위에 큰 pane, 격자 중 하나로 타일 pane을 다시 배치한다. floating pane과 묶음은 그대로 떠 있다.

## 세션 저장과 불러오기

prefix(`C-b`) 뒤 `C-s`나 rmux 메뉴의 세션 저장은 지금 서버의 세션, 창 이름과 순서, pane 배치(floating·묶음 포함), pane마다 작업 디렉터리와 실행 중이던 명령을 저장본으로 남긴다. 저장 결과는 상태줄에 잠깐 표시한다. 따로 누르지 않아도 15분마다 자동으로 저장하며, 마지막 저장본과 달라진 것이 없으면 새로 만들지 않는다. `set -g @rmux-autosave 30`처럼 분 단위로 바꾸고 `off`나 `0`으로 끈다. 자동 저장은 서버마다 하나만 돌고, 레이어를 끄거나 서버가 끝나면 멈춘다. 같은 초에 저장본이 둘 생기면 두 번째 이름에 `-2`를 붙인다.

prefix 뒤 `C-r`이나 rmux 메뉴의 세션 불러오기는 저장본 목록을 시간순으로 보여 준다. 항목을 고르면 그 저장본의 세션을 새로 만든다.

- 같은 이름의 세션이 이미 있으면 건너뛴다. 예외는 방금 시작한 빈 세션이다. 10분 안에 명령 없이 만들어졌고, 창과 pane이 하나이며, 셸이 입력을 기다리고, 그 셸에 멈춘 작업이나 백그라운드 작업이 없고, 스크롤 기록이 없고, 커서가 위쪽 네 줄 안에 있으면 저장본으로 바꾼다. 불러오는 동안 그 세션에 다른 클라이언트가 붙어 있거나 조건이 깨지면 두 세션을 모두 남기고 새 세션 이름 뒤에 `-restored`를 붙인다.
- 각 pane은 저장한 디렉터리에서 새 셸로 시작한다. 셸만 있던 pane에는 아무것도 실행하지 않는다.
- 실행 중이던 명령은 허용 목록(`vi vim nvim view emacs nano micro hx helix less more man tail top htop btop`)에 있을 때만 셸에 입력해 다시 실행한다. `set -g @rmux-restore-commands "vim less npm"`처럼 목록을 바꿀 수 있다. 다른 명령과 제어 문자가 든 인자는 저장하지 않는다. 묶인 세션(`new-session -t`)이 함께 쓰던 pane의 명령은 한 번만 실행한다.
- native session을 보고하는 코딩 에이전트(Codex, Claude Code 등)는 그 세션을 재개하는 명령으로 다시 연다.
- 저장한 배치를 적용할 수 없으면 모든 pane을 타일로 놓는다.
- 불러온 뒤 저장할 때 활성이던 세션으로 클라이언트를 옮긴다. 결과와 오류는 상태줄에만 표시하고 pane에는 쓰지 않는다.

저장본은 `$XDG_DATA_HOME/rmux/sessions` 또는 `~/.local/share/rmux/sessions`에 `0600` 파일로 남는다. 디렉터리는 `0700`이다. 자동·수동 저장본을 종류마다 최근 20개씩 보관한다. 명령줄 인자가 그대로 저장되므로 비밀값을 명령줄로 넘기는 프로그램은 저장본에도 남는다. 화면 내용과 스크롤 기록은 저장하지 않는다.

스크립트에서는 다음 명령을 쓴다.

```sh
rmux-agent session save            # 지금 저장
rmux-agent session save --auto     # 달라졌을 때만 자동 저장본으로 저장
rmux-agent session list            # 저장본 목록(JSON)
rmux-agent session restore [NAME]  # NAME이 없으면 가장 최근 저장본
```

## 상태줄 위치

설정 화면의 상태줄 위치는 위, 아래, 왼쪽 사이드바, 오른쪽 사이드바 중 하나다. `set -g status-position left|right`로도 바꿀 수 있다.

사이드바는 모든 창의 같은 쪽에 그려진다. 위에서부터 `status-left`, 창마다 한 줄, 맨 아래 `status-right`를 표시한다. 창 줄은 `window-status-format`과 창 스타일을 그대로 쓰고 줄 어디를 눌러도 그 창을 고른다. 폭은 `@rmux-status-width`(기본 24, 8~80)다. 터미널 폭이 사이드바 폭보다 10열 이상 넓지 않으면 사이드바를 그리지 않는다. 메시지와 command prompt는 맨 아래 줄 전체에 겹쳐 표시한다.

사이드바가 있으면 pane이 터미널 전체 폭을 차지하지 않는다. 좌우 여백(DECSLRM)을 지원하지 않는 터미널에서는 스크롤할 때 pane을 다시 그리므로 출력이 많은 작업에서 느릴 수 있다.

## 좁은 화면

버튼보다 세션·창·pane 이름을 먼저 줄이고 `…`로 끝낸다. 버튼이 들어가지 않으면 덜 중요한 것부터 뺀다.

| 위치 | 줄이는 순서 |
| --- | --- |
| 위·아래 상태줄 | 70열 미만에서 시계, 40열 미만에서 세션 이름(40~55열에서는 `client_width - 36`칸으로 줄임), 24열(한국어 20열) 미만에서 `Settings`를 뺀다. 창 이름은 `client_width / 4`칸까지 보여 확대·알림 표시가 남는다. |
| 사이드바 맨 위 | `rmux`와 접기·펴기 버튼 `<`·`>`는 항상 남고 세션 이름을 줄인다. |
| 사이드바 맨 아래 | 폭 23칸(한국어 21칸) 미만에서 시계, 17칸(15칸) 미만에서 `New` 글자, 13칸(9칸) 미만에서 `Settings`를 뺀다. |
| pane 제목 | pane 폭 33열 미만에서 `float`, 26열 미만에서 `+`, 23열 미만에서 `zoom`, 15열 미만에서 `x`를 뺀다. |
| rmux 메뉴 | 창이 14행이나 28열(한국어 36열)보다 작으면 구분선 없이 짧은 이름을 쓴다. 13행 미만에서 레이아웃, 12행 미만에서 키 목록과 설정 다시 읽기, 10행 미만에서 새 세션, 9행 미만에서 분할 두 개를 뺀다. |

뺀 `Settings`는 `rmux` 메뉴의 첫 항목으로 열 수 있다. 설정 화면이 좁으면 값 버튼이 다음 줄로 넘어가고, 긴 결과 문구는 아래쪽 안내 줄까지 써서 두 줄로 보여 준다.

## 설정 화면

`Settings` 버튼이나 rmux 메뉴의 설정은 현재 창 위에 modal pane으로 `rmux-agent settings`를 연다. 마우스와 키보드(Tab, 방향키, Enter, q)로 같은 일을 할 수 있다.

| 항목 | 설정 |
| --- | --- |
| 상태줄 | 위치, 표시, 사이드바 너비, 시계 |
| 창 분할 | pane 제목줄, 스크롤바, 경계선 |
| 마우스와 입력 | 마우스, 번호 시작, 창 번호 다시 매기기, 스크롤 기록 |
| 모양 | 테마(어둡게, 밝게, 터미널 색, tmux 기본), 언어(English, 한국어) |
| rmux UI | 레이어 켜기·끄기, 모든 설정 초기화 |

값을 고르면 서버가 받아들인 뒤 저장한다. 고른 옵션은 바로 적용하고, 그 선택에 딸린 다른 옵션(예: 테마의 색)은 아직 레이어 값 그대로일 때만 다시 적용해 사용자 설정을 보존한다. 적용 결과는 서버의 실제 값을 다시 읽어서 표시한다. 이 세션이나 창에 따로 정한 값이 가리면 가려진다고 알린다. 저장하지 못하면 rmux를 끌 때까지만 적용된다고 표시한다. `~/.tmux.conf` 등이 같은 옵션을 정하면 그 값이 표시되며, 여기서 고른 값은 rmux를 다시 시작하면 사용자 설정에 밀린다.

스크립트에서는 화면 없이 쓸 수 있다.

```sh
rmux-agent settings --set @rmux-status-position left --set @rmux-theme light
rmux-agent settings --layer off     # 순수 tmux 기본값으로
rmux-agent settings --reset         # 저장한 선택 지우기
rmux-agent settings --get
```

rmux 밖에서는 `--socket PATH`로 서버를 지정한다.

## 적용 순서와 파일

`-f` 없이 시작하면 다음 순서로 읽는다.

1. `$XDG_CONFIG_HOME/rmux/settings.conf`(절대 경로일 때) 또는 `~/.config/rmux/settings.conf`: 설정 화면이 저장한 `@rmux-*` 선택
2. 코어에 내장한 UI 레이어(`core/rmux-ui-layer.conf`)
3. `/etc/tmux.conf`, `~/.tmux.conf`, `$XDG_CONFIG_HOME/tmux/tmux.conf`, `~/.config/tmux/tmux.conf`

사용자 tmux 설정이 가장 나중이라 레이어보다 우선한다. `rmux -f FILE`로 시작하면 1과 2를 읽지 않으며 stock tmux와 같은 기본값이 된다.

`settings.conf`는 `set -g @rmux-KEY VALUE` 줄만 관리하고 다른 줄은 보존한다. 파일은 0600으로 원자적으로 교체한다. 심볼릭 링크이거나 일반 파일이 아니면 덮어쓰지 않고 현재 세션에만 적용한다.

레이어는 tmux 옵션과 기본 바인딩이 없는 키만 쓴다. 마우스는 `MouseDown1Control0`~`6`와 pane 제목의 `MouseUp1Control3`·`MouseDrag1Control3`, 키보드는 prefix 뒤 `C-s`·`C-r`이다. 설정 화면은 언어를 바꿀 때 prefix 키를 다시 정하지 않으므로, 사용자 설정 파일에서 `C-s`·`C-r`을 따로 바인딩했다면 그 바인딩이 남는다. 각 바인딩의 설명은 `rmux-ui:`로 시작한다. 레이어를 끄면 레이어가 정한 옵션과 색·메뉴용 `@rmux-*` 옵션을 되돌리고 `rmux-ui:` 바인딩만 푼 뒤 사용자 tmux 설정 파일을 다시 읽는다. 저장한 선택(`@rmux-*`)과 `@rmux-agent`는 남는다. 레이어를 다시 켜거나 초기화한 뒤에도 사용자 tmux 설정 파일을 다시 읽는다. 두 설정 화면이 동시에 저장하지 않도록 설정 디렉터리에 잠금 파일을 쓴다.

## 알려진 제한

- `rmux` 메뉴의 tmux 설정 다시 읽기는 `/etc/tmux.conf`, `~/.tmux.conf`, `~/.config/tmux/tmux.conf`를 읽는다. `$XDG_CONFIG_HOME/tmux/tmux.conf`는 설정 화면의 레이어 켜기·끄기·초기화에서만 다시 읽는다.
- 메뉴 항목과 pane 메뉴의 문구는 tmux 기본값이라 영어로 표시된다. rmux 메뉴, 버튼, 설정 화면은 언어 설정을 따른다.
- rmux 밖에서 `--set`을 쓰면 현재 pane을 알 수 없어 세션·창별 덮어쓰기를 확인하지 않는다.
